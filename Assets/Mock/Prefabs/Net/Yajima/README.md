# ルーム接続テスト 操作手順

## テスト画面を開く

1. Unityで `Assets/Mock/Scenes/Net/Yajima/NetTest.unity` を開く。
2. Unity上部の再生ボタンを押す。
3. **Game**ビューで操作する。画面が小さい場合は、Gameタブをダブルクリックして拡大する。

## 1台で試す

1. **PORT**を `7770` のままにする。
2. **HOST**を押す。
3. 接続状態が `SERVER Started`、`CLIENT Authenticated` になるまで待つ。
4. **ROOM NAME**にルーム名、**SEATS**に定員（1〜16）を入力する。
5. **CREATE ROOM**を押す。
6. 右側にルーム名と自分のメンバー情報が表示されたことを確認する。
7. **READY**を押す。
8. **START ROOM**を押す。
9. `IngameTest`シーンに切り替わり、接続用UIが消えたら移動確認完了。

移動先は `Assets/Mock/Scenes/Net/Yajima/IngameTest.unity` です。

## 複数端末で試す

### ホスト側

1. 使用する端末を同じLAN・Wi-Fiに接続する。
2. Windowsの「設定」→「ネットワークとインターネット」から、使用中の接続のプロパティを開き、ホスト端末の **IPv4アドレス**を確認する。
3. NetTestを再生する。
4. **PORT**に `7770` を入力して **HOST**を押す。
5. `CLIENT Authenticated` が表示されたら、ルーム名と定員を入力して **CREATE ROOM**を押す。定員は参加する全員分にする。
6. 参加する人に、ホストのIPv4アドレスとポート番号を伝える。

### 参加側

1. 別端末でNetTestを再生する。
2. **SERVER IP**にホスト端末のIPv4アドレスを入力する。
3. **PORT**にホストと同じ番号を入力する。
4. **CLIENT**を押す。
5. `CLIENT Authenticated` が表示されるまで待つ。
6. 左側の一覧で、参加したいルームの **JOIN >** が表示された行を押す。
7. 右側にルーム名とメンバーが表示されたことを確認する。

同じPCで別に起動したテスト画面から参加する場合は、SERVER IPに `127.0.0.1` を入力する。別端末から参加する場合は、ホスト端末のIPv4アドレスを入力する。

### 全員で開始する

1. ホストを含む参加者全員が **READY**を押す。
2. 全員の表示が `READY` になったことを確認する。
3. `[OWNER]` と表示されている人が **START ROOM**を押す。
4. 各端末で `IngameTest`シーンに切り替わり、接続用UIが消えたことを確認する。

## 開始前の退出・切断

| 操作 | 押すボタン・手順 |
| --- | --- |
| Readyを取り消す | 開始前に **CANCEL READY**を押す。 |
| ルームから退出する | **LEAVE**を押す。 |
| 別のルームに参加する | **LEAVE** → 一覧の参加したいルームの行を押す。 |
| 一覧を更新する | **REFRESH**を押す。一覧は約3秒ごとにも更新される。 |
| 接続を終了する | **DISCONNECT**を押す。ホスト側で押すと参加者も切断される。 |
| IP・ポートを変更する | **DISCONNECT** → 入力を変更 → **HOST**または **CLIENT**を押す。 |
| シーン移動後にやり直す | 全端末で再生を停止 → NetTestを開く → 再生 → 接続からやり直す。 |
| テストを終了する | 開始前は **DISCONNECT**を押して再生を停止する。シーン移動後はUnityの再生を停止する。 |

## サーバー専用で試す場合

1. サーバーにする端末でNetTestを再生する。
2. **PORT**を入力して **SERVER ONLY**を押す。
3. `SERVER Started` が表示されたことを確認する。
4. 参加する端末では、そのサーバー端末のIPv4アドレスと同じポート番号を入力し、**CLIENT**を押す。
5. 接続した参加者のうち1人が **CREATE ROOM**を押し、他の参加者は一覧から参加する。

## 操作が進まないとき

| 状況 | 確認・操作 |
| --- | --- |
| 接続できない | ホストが起動済みか、SERVER IPとPORTが合っているか、同じLAN・Wi-Fiかを確認して再接続する。 |
| ホストが起動しない | **DISCONNECT**を押し、PORTを別の番号（例：`7771`）に変更して再度 **HOST**を押す。参加側も同じ番号に変更する。 |
| ルームが一覧に出ない | **REFRESH**を押す。ホスト側で **CREATE ROOM**を押したかも確認する。 |
| ルームの行を押せない | 参加中なら **LEAVE**を押す。満員・`IN GAME` のルームは別のルームを選ぶ。 |
| START ROOMを押せない | 自分に `[OWNER]` が付いているか、全員が `READY` になっているかを確認する。 |
| 入力エラーが出る | ルーム名は1〜48文字、定員は1〜16、ポートは1〜65535で入力し直す。 |
